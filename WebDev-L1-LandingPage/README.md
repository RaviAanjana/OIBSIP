# Oasis Infobyte - Landing Page (Level 1, Task 1)

A complete, professional, and fully responsive landing page built for the Oasis Infobyte Web Development & Designing Internship - Level 1, Task 1.

## Project Overview

This landing page showcases the Oasis Infobyte internship program with a modern design, smooth navigation, and engaging content sections. It's built using only HTML5 and CSS3, with no JavaScript, frameworks, or libraries.

## Features

- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices
- **Sticky Navigation**: Fixed/sticky navbar with smooth scrolling
- **Hero Section**: Eye-catching headline, description, and call-to-action button
- **About Section**: Information about Oasis Infobyte with feature cards
- **Opportunities Section**: Three internship levels displayed in card layout
- **Call-to-Action**: Prominent section encouraging users to apply
- **Footer**: Contains copyright info and useful links
- **Hover Effects**: Smooth transitions and hover animations
- **Semantic HTML**: Uses proper HTML5 semantic elements
- **Accessibility**: Includes alt text, proper labels, and reduced motion support
- **CSS Flexbox & Grid**: Modern layout techniques

## How to Run Locally

1. **Download or Clone**: Download this folder to your local machine
2. **Navigate**: Open the `WebDev-L1-LandingPage` folder
3. **Open in Browser**: Double-click `index.html` or right-click and open with your preferred web browser (Chrome, Firefox, Edge, Safari, etc.)

Alternatively, you can use a local server:

- **Using VS Code Live Server**: Install the "Live Server" extension, right-click `index.html`, and select "Open with Live Server"
- **Using Python**: Run `python -m http.server 8000` in the project directory and navigate to `http://localhost:8000`
- **Using Node.js**: Run `npx serve .` in the project directory

## How to Take Screenshots for GitHub Submission

### For Desktop
1. Open the page in a browser at full desktop resolution (1920x1080 recommended)
2. Use browser screenshot tools or:
   - **Chrome/Edge**: Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac), search "Capture screenshot"
   - **Firefox**: Right-click → Take Screenshot
   - **Windows Snipping Tool** or `Win+Shift+S`
   - **Mac**: `Cmd+Shift+4`

### For Tablet
1. Open Developer Tools (`F12` or `Ctrl+Shift+I`)
2. Toggle device toolbar (`Ctrl+Shift+M` or `Cmd+Shift+M`)
3. Select a tablet preset (e.g., iPad) or set custom dimensions (768px width)
4. Take a screenshot

### For Mobile
1. Use Developer Tools device emulation
2. Select a mobile device (e.g., iPhone 12/13, Samsung Galaxy)
3. Set viewport to mobile size (375px - 480px)
4. Take a screenshot

Save all screenshots in the `screenshots/` folder with descriptive names like:
- `desktop-view.png`
- `tablet-view.png`
- `mobile-view.png`
- `hero-section.png`
- `navigation.png`

## Customization

To customize this landing page for your needs:

1. **Colors**: Edit the color values in `style.css` (search for color codes like `#4a90e2`)
2. **Content**: Update text in `index.html` in each section
3. **Images**: Replace the SVG placeholder in the hero section with your own image by replacing the `.hero-image-placeholder` content
4. **Links**: Update the footer links and CTA button URLs as needed
