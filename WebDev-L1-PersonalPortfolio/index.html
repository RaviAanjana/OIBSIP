Busy Buy

Busy Buy is a simple e-commerce web application built using React.js, JavaScript, HTML, CSS, Bootstrap, Firebase Authentication, and Firestore Database. The application allows users to browse products, filter items by category, manage their shopping cart, and place orders seamlessly. User authentication is implemented using Firebase, ensuring secure login and signup functionality. The platform provides a smooth shopping experience with real-time data management through Firestore.

A sleek, responsive web-based music player built with vanilla HTML, CSS, and JavaScript.
